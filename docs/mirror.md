这是科学空间的非官方、非商业知识库。主题与系列索引保留，正文仅作必要格式转换。Markdown、源码视图、复制和下载均附苏剑林署名、原文链接、CC BY-NC-ND 2.5 CN 与项目声明。命令见 [维护说明](maintenance.md)。

## 如何保证忠于原文

采用 Python 3.11、uv、requests、BeautifulSoup 和 markdown-it-py 独立回读校验。原始 HTML 已包含 LaTeX，因此使用确定性的正文边界和转换规则，无需 Crawl4AI、浏览器抓取或 LLM 改写。

校验源 DOM 与转换结果的文字、公式、图片混合序列，并独立比较标题层级、链接、图片和代码序列，检测缺失、重复、乱序与变化。LaTeX 保留原定界符、反斜线、空格、环境、宏、标签和顺序，只还原 HTML 实体及传输换行。代码精确核对字符和缩进，不当作公式处理。

普通正文仅折叠排版空白，不删除单词间空格；不比较所有 CSS 视觉效果。复杂历史结构采用独立的 HTML 逐节点、属性和顺序校验。构建重新读取快照与 Markdown 校验，并核对保存的哈希，不只信任报告中的 `passed`。

只接受已确认的正文容器和尾部模板。评论、侧栏、推荐、打赏与引用模板不进入快照。未知结构失败关闭，保留已确认正文快照供离线修复，不输出可用 Markdown。原文转载来源说明仍予保留。

阅读器通过受限 DOM API 创建页面，不执行文章脚本。本地 MathJax 4.1.3 使用 CommonHTML 与随站提供的 TeX 数学字体排版，禁用动态扩展下载；原文 AMScd 用预加载扩展兼容，Markdown 不改写。阅读排版、目录和站内导航只影响页面展示，复制和下载仍使用已校验原文件。

图片保持原位置和原始字节。科学空间托管的图片自动保存到 `data/articles/<id>/images/`，`images.json` 记录原地址、SHA-256、HTTP 校验头及失败重试状态。Markdown 保留原图 URL，网站优先展示经校验的本地副本；站外图片保留外链。旧式脚本、Flash、ActiveX 等保留位置与转义原始信息，阅读器不执行这些内容。

## 更新与撤回

配置位于 [`config/mirror.json`](../config/mirror.json)。

| 配置 | 当前值 | 作用 |
| --- | --- | --- |
| `withdrawn_ids` | `[]` | 主动撤回 ID，停止更新且构建不导出 |
| `refresh_days` | `30` | 到期复查间隔 |
| `refresh_per_run` | `25` | 每次复查上限，按最早检查时间轮换 |
| `max_stale_days` | `120` | 超期且未经复查的文章不进入公开构建 |

请求至少间隔 3 秒，严格串行并遵守 robots.txt、Retry-After 和条件请求。统一命令处理失败冷却、重试与断点续跑。离线转换不延长源站检查时间。404/410 自动撤回；主动撤回将 ID 加入 `withdrawn_ids`，再运行离线更新。重建会移除失效正文及直接下载地址。

已部署网站需要重新部署才能撤回，Git 历史与用户副本不会随之消失。构建或校验异常时保留此前完整网站，本次失败产物不会自动发布。

维护者选择缓存科学空间主域及 `album`、`bbs` 子域托管的图片；这是下载范围规则，不表示托管者拥有全部图片版权或项目已逐图核验许可。保留所有原图、图注、来源和第三方署名，不将图片重新许可为 MIT。

原创代码使用 MIT；文章、快照与图片不改用 MIT。MathJax 代码使用独立 Apache-2.0 许可；TeX 数学字体保留原版权与 SIL Open Font License 1.1，化学扩展字体保留 GUST Font License，见 `web/vendor/mathjax/NOTICE.md` 和对应字体许可文件。

- `1023`、`116`、`49` 原文公式定界符异常保持原样，展示提示，公式总数标记为未知。内容一致性通过不等于原文数学正确，也不保证所有 LaTeX 都能排版。
